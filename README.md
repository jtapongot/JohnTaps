# Personal Portfolio — Digital Operations

A responsive, single-page personal portfolio built with plain HTML, CSS, and JavaScript. Visual direction: dark navy, warm gold, clean typography, and a responsive layout.

## Deploy free with Cloudflare Pages

1. Open the Cloudflare dashboard and go to **Workers & Pages**.
2. Choose **Create application** → **Pages** → **Connect to Git**.
3. Select the GitHub repository `jtapongot/butodco`.
4. Configure: production branch `main`; framework preset `None`; build command blank; build output directory `/`.
5. Choose **Save and Deploy**. Cloudflare will provide a `.pages.dev` address.
6. Future commits to `main` will trigger automatic deployments.

No paid plan, build service, or framework is required for this static site. Cloudflare's free-plan limits and account terms apply.

## Customize before sharing

- Update the page title, role, introduction, and portfolio copy in `index.html`.
- Replace generic project summaries with approved case studies and real outcomes.
- Change the email action to your preferred public contact address.
- Update the skills and tools to reflect the work you want to showcase.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive navy-and-gold design
- `script.js` — mobile navigation, active section, and current year

## Run locally

Open `index.html` in a browser. No dependencies or build step are required.
